# Dashboard account followers and upload video types

Team overview uses the existing day selector. Each stacked bar represents one Singapore calendar day, ending today, and uses the last profile snapshot of each platform on that day. The x-axis shows date and sum of enabled platforms. Hover or keyboard focus reveals platform counts in a floating tooltip; leaving the chart dismisses it. A missing observation stays null (never zero or a forward-filled current total); partial sums are labelled Available total in the tooltip. Cross-platform totals are not deduplicated people. Source: profile_metric_snapshots; cache version dashboard:v6.

Uploads require one primary content goal: repost (shared worldview/core values), saves (useful value), or website_visit (trust and curiosity). These describe creative intent, not measured conversions. Browser and publish API validate the selection; submitForReview persists uploads.video_type in the submission transaction. Existing/imported records retain null and appear unclassified in approval details. This is internal metadata, not part of the published caption.

Test only: node scripts/verify-followers-video-types.cjs with the test environment loaded. It uses an isolated database schema and synthetic records; no external publishing or notifications. Covers required/invalid choices, persistence of all choices, daily ranges, Singapore boundaries, last snapshot, zero and missing values.
